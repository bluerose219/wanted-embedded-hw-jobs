## 2. 데이터 수집 (`scripts/fetch.py`)

- 원티드 화면 HTML을 긁는 대신 페이지가 내부적으로 호출하는 **JSON API**를 찾아서 사용했습니다.
  - 목록: `GET /api/v4/jobs?tag_type_ids=658&tag_type_ids=672&limit=100&offset=…` (658 = 임베디드 개발자, 672 = 하드웨어 엔지니어)
  - 상세: `GET /api/v4/jobs/{id}` → `requirements`(자격요건), `preferred_points`(우대사항), `main_tasks`(주요업무)
- 상세 조회는 `ThreadPoolExecutor(8)`로 병렬 처리하고, 실패하면 3번까지 다시 시도합니다.

## 3. 가공·키워드 추출 (`scripts/proc.py`)

- 약 60개 기술 키워드를 **정규식 사전**으로 정의하고, 언어 / OS·플랫폼 / 프로세서 / 통신·인터페이스 / HW 설계 / 도구 / 도메인 / 기본 역량 8개 그룹으로 묶었습니다.
  - 예: `C/C++` ← `C\+\+|C\s*(언어|기반)|임베디드\s*C …`, `UART/SPI/I2C` ← `uart|\bspi\b|i2c|gpio`
- 키워드는 **공고 단위**로 셉니다(한 공고에 여러 번 나와도 1건). 자격요건과 우대사항은 따로 셉니다.
- 학력 요건, 경력 구간(신입 / 1~2 / 3~4 / 5~6 / 7년+), 직군(임베디드 / 하드웨어 / 둘 다)도 분류했습니다.
- 결과: `data/jobs.json`(234건), `data/kwgroups.json`(키워드-그룹 매핑)

실습 중 만난 오류와 해결 방법:

| 오류 | 해결 |
|---|---|
| Windows 콘솔 `cp949` 인코딩 에러 | `sys.stdout.reconfigure(encoding='utf-8')` |
| 상세 응답에 `annual_from`(경력) 없음 | 목록 응답에서 가져와 id로 합치기 |
| 카테고리 API 404 | 페이지 HTML에서 카테고리명 파싱 |

## 7. 직접 다시 돌려보기

```bash
cd scripts
python fetch.py          # raw.json 생성 (몇 분 걸림)
python proc.py raw.json  # jobs.json, kwgroups.json 생성 + 통계 출력
```

Python 3.9 이상이면 되고, 표준 라이브러리만 씁니다.
